MinkLauncher OpenSource is a focused Android home-screen launcher and keyboard-first assistant designed around fast input and low visual noise.

The responsive Home panel combines a preview of up to five to-dos with eight configurable icon shortcuts. A compact drawer holds up to eight chosen apps, while every installed launcher app remains one keyboard search away.

On a physical-keyboard phone, just start typing from Home. The already-focused Magic Box appears with the first character preserved; no tap is required. It can also open over another app when MinkLauncher OpenSource is selected as Android’s assistant.

Magic Box commands:

• @ — choose a contact, then send carrier SMS or hand the message to an integrated messaging app
• # — choose a contact, confirm, then call or choose a calling provider
• - — add an internal to-do
• / — create a multiline note through an installed notes app
• + — create a calendar event
• ? — find and immediately launch an installed app
• Plain text — search local filenames, open a web search, or hand the query to a selected compatible AI app

To-dos can be added, checked, edited, confirmed before deletion, and reordered by drag. Local file results are grouped into photos, videos, documents, and audio, with thumbnails where Android provides them. Document search uses only folders you explicitly select through Android's system folder picker.

Optional spaces remain one swipe away:

• Conversations groups active Android message and email notifications into compact threads. Inline reply is offered only when the originating app supplies Android’s reply action, and content remains transient in memory.
• Mink’s Day measures foreground time and launch counts for the Android Social-category apps or custom apps the user chooses to include. Set a collective limit from 0 to 23 whole hours, then pause those apps in MinkLauncher all the time, only after the limit, or never. Paused apps are hidden from Magic Box and app drawers while shortcut tiles remain visible with a reminder. This is a launcher barrier, not a system app suspension or parental-control feature. Other apps never enter Mink’s Day totals.
• Widgets hosts up to four Android widgets with grouped provider previews, correct responsive sizing, reordering, and removal.

Integrated messaging:

• Choose System Messages or an installed supported messaging app in Settings
• Send automatically with that app, or choose an app for each one-time @ message
• Supported deep links carry the contact and message when the receiving app allows it
• Other integrations carry the message and let you choose the contact in the receiving app
• Returning to Mink keeps your selected contact and message until you send or clear it
• Conversation replies still use the reply action supplied by the notification’s source app

Privacy is a core feature:

• No accounts, ads, analytics, trackers, or application server
• An optional, twice-daily GitHub release-metadata check shows a passive update icon in the Home header; GitHub receives normal connection metadata but no launcher content, and the app never downloads or installs APKs
• Queries, to-dos, settings, conversations, usage analysis, and filename indexing stay on the device
• Android cloud backup is disabled
• Notification, Usage, Accessibility, and Assistant special access are optional and explained before Android Settings opens
• The lock Accessibility Service performs only Android’s Lock screen action and cannot inspect window content
