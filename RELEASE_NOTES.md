Open 3.2.2 refines Home discovery, Magic Box input, Quick Apps, Favorites, and demo capture without changing the backup format or permission model.

- **Choose the keyboard that fits:** Magic Box uses Mink Keyboard by default. A new top-level Keyboard setting can switch to the current Android system keyboard and hides Mink-only customization while keeping `@`, `#`, `-`, `/`, `+`, and `?` actions intact. The choice is portable, and older backups continue to default to Mink Keyboard.
- **Hot keys start actions instead of becoming text:** Magic Box now treats a hot key as the catalyst for its route, keeps drafts focused through each step, and preserves physical-keyboard input corrections without leaving the trigger character in the message or query.
- **A guided tour of Home:** Existing and new users receive a focused spotlight walkthrough for folders, MinkSpace, Magic Box, keyboard controls, header actions, and the gestures that move between Home, Widgets, Mink's Day, See All, and notifications.
- **Quick Apps behaves like a folder:** Tapping Quick Apps inside Quick Drawer now opens its contents directly in the shared folder surface. The plus button opens its eight-item picker, while regular Home folders support up to 12 items and use the same count language.
- **Smoother Home and keyboard layout:** Home's top controls no longer shift the Magic Box while paging, the launcher keyboard animates into place, and portrait height uses clear 30%, 40%, and 50% stops with 40% as the default.
- **Favorites follow their source:** Integrated Favorites can retain provider shortcut artwork and updated provider names. A deliberately custom Favorite name remains under the user's control.
- **Less repetitive Adrift sessions:** Each Adrift launch starts from a shuffled media sequence instead of replaying the same opening order.
- **Demo Studio:** Demo Mode now has one capture-focused settings surface for repeatable Home, Conversations, Favorite-attention, Quick Apps, and search scenarios.

The permanent **Join Google Play beta** button remains in Quick Drawer. No new permissions, analytics, accounts, or network services are introduced. Portable backup schema version 3 remains unchanged, older schema-3 backups continue to import, and device-bound data remains device-bound.
