Open 3.0.0 makes MinkLauncher a more complete keyboard-first home and introduces MinkPad.

- **MinkPad:** Turn an Android 9 or newer phone into a Bluetooth keyboard, trackpad, media controller, or TV remote. Pair and switch between saved receiving devices, tune pointer and scrolling behavior, use hardware or software text input, and keep input on the direct Bluetooth connection.
- **More flexible MinkSpace:** Add an Android widget as a mini-app, replace or configure it without leaving Home, enter interaction mode for nested widget controls, choose and reorder every mini-app, or open To-dos directly when its mini-app is hidden.
- **A new Settings layout:** Compact devices use bottom sections while tablets and foldables use a two-pane section menu. Nested pages keep a predictable Back stack, and Settings remains available in Recents while it is open.
- **More appearance control:** Choose from sixteen bundled wallpapers, keep a personal photo ready for reuse, adjust launcher font size and color live, import a local `.ttf` or `.otf` font, and keep Mink icon colors beside the icon choice they affect.
- **Keyboard and device fixes:** Hardware hotkeys better survive keyboard auto-spacing and correction, Zinwa-style directional trackpads move through the app alphabet, large system fonts no longer hide widget confirmation controls, and wallpaper and widget replacement flows refresh more reliably.
- **A much smaller install:** Optimized bundled wallpapers and release shrinking substantially reduce the APK and installed code footprint without lowering wallpaper resolution.

MinkPad temporarily adds `Pro Controller - MinkPad` to the phone's normal Bluetooth name while a session is active and restores the original name when the session ends. Existing Bluetooth accessories can disconnect or compete for the radio during a session. Nearby-device discovery runs only when the user requests it, and MinkLauncher does not save typed text, pointer coordinates, or scan results.
