Open 1.5.5 improves the Virtual Contact Card, large-display Settings, and release handoffs.

- Contact photos now remain valid for Compose to draw after loading, fixing the crash that could occur when showing a vCard with a selected photo.
- A new optional **Show values on card** setting displays selected link names and values on the Home vCard. The preference remains encrypted with the card and is preserved by portable backup.
- Settings now follows the optional two-panel layout on eligible tablets and unfolded foldables: sections remain visible beside one active detail page, while deeper navigation stays within that detail pane.
- Update prompts now offer separate GitHub and F-Droid routes and explain that F-Droid publication may arrive later. Both release pages are also available directly from About.

This update adds no new runtime permission prompt.
