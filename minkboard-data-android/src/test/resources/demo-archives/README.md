# MinkBoard demo archives

These encrypted `.minkboard` files are importable demo boards and regression fixtures for the
portable archive codec. Every archive uses the demo-only passphrase `minktest123`.

Never use this shared passphrase for real user data.

The seven template fixtures preserve their canonical status names, colors, order, and Done flags.
The custom command-center fixture exercises a larger board. The massive product roadmap supplies
eight intentionally uneven statuses for overview and performance testing. Across the set, cards also cover due
dates, major-card markers, details, subtasks, and completed subtasks.
